# PrestaShop-Testing-Project

##  Description
Projet de test du site PrestaShop Demo basé sur les standards ISTQB.

##  Objectifs
- Concevoir des cas de test
- Identifier les fonctionnalités critiques
- Préparer l'exécution des tests

##  Structure du projet

###  Phase 1 – Analyse & Conception
- Plan de test
- Stratégie de test
- Scénarios de test
- Cas de test
- Matrice de traçabilité

###  Phase 2 – Exécution (à venir)
- Résultats des tests
- Rapports de bugs
- Dashboard
